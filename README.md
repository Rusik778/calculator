# Калькулятор — домашня робота до лекції 4

Автор: Руслан Чухно.

## Запуск

Відкрийте термінал у цій папці й виконайте:

```text
python main.py
```

Виберіть номер дії; для виходу введіть 0. Десятковий роздільник — крапка.
У дії 6 перше число — величина, друге — відсоток: 200 і 15 дають 30.
Калькулятор призначений для звичайних скінченних чисел.

## Файли

- calc.py — add, sub, mul, div, power, percent.
- main.py — меню та обробка введення.
- tools.py — is_even, max3, імпортовані у main.py.
- p2_digits.py — задача П2 про кількість цифр у вигляді функції.
- digit_sum_rec.py — рекурсивна сума цифр; для чисел помірної довжини.
- test_calculator.py — автоматичні перевірки: python test_calculator.py.
- report.md — звіт із результатами, автором та полем для групи.
- .git — справжня локальна історія змін; не видаляйте її.
