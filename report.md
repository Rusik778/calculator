## Опис роботи

Арифметичні функції повертають результат через return, а main.py відповідає за введення та виведення. Функція div повертає None при діленні на нуль. Power має показник степеня n=2 за замовчуванням; недопустимий для дійсного результату степінь повертає None.

Умова не визначає формулу percent; у реалізації percent(value, rate) обчислює rate відсотків від value за формулою value*rate/100. Наприклад, percent(200, 15)=30. У меню спочатку вводиться число, потім відсоток.

У tools.py функція is_even перевіряє парність, max3 знаходить найбільше з трьох. У main.py вони викликаються як tools.is_even та tools.max3.

count_digits(n) відокремлює обчислення від введення. Нуль має одну цифру, від’ємний аргумент викликає ValueError, який основна програма обробляє. Рекурсивна digit_sum_rec бере модуль числа, повертає одну цифру в базовому випадку та додає останню цифру до суми решти.

## Самоперевірка

1. Параметр — ім’я в заголовку функції; аргумент — значення під час виклику.
2. Функція без return повертає None.
3. print показує значення людині, return повертає його програмі.
4. Рекурсія потребує базового випадку та наближення до нього.
5. Звичайні параметри зі значеннями за замовчуванням розміщують після обов’язкових.
6. Локальна змінна належить області видимості функції й недоступна зовні за її локальним ім’ям.
7. Перший коміт: git init, git add ., git commit -m "...".
8. Надсилання комітів на GitHub: git push.
